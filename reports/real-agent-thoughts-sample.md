# 真实模型（grok-4.6）智能体思考样本 — 原始文字留证

> 用途：以**真实推理模型**驱动主循环，把每个居民每 tick 的 LLM 输出原文落盘，用于判断
> 「智能体决策/对话机制」当前的真实形态。本文只放**原始文字**与可核对的调用事实，不做美化。


## 运行事实（可核对）

| 项 | 值 |
| --- | --- |
| provider / model | `a6api` / `grok-4.6` |
| 规模 | 2 tick × 3 居民（agentCount=3），seed 1 |
| gateway 统计 | requests=**7** successes=**7** failures=**0** |
| 每 tick 真实调用 | 3 次（= 居民数），tick2 多出 `agent_000000000029`（人口 3→4） |
| 产出字段 | `run().steps[].decisions[].thought`（loop.js:714） |
| 单次延迟（历史基线 p50） | ≈26 s（见 reports/bench-baseline-real.md） |

## 主循环里 LLM 的唯一调用点

```js
// src/runtime/orchestrator/loop.js:634-635
const situation = `当前处境：${(inbox[agentId] ?? []).map((p) => p.topic).join('、') || '一切如常'}。你决定采取行动「${decision.action}」。`;
const thought = await ai.thought.generate(agentContextOf(record), situation);
```

要点：**行动 `decision.action` 在调用 LLM 之前就已由评分函数选出**，并作为既成事实写进提示词。

## captain 的结构性判读（均附文件:行，可复核）

### ① 主循环只有 1 个 LLM 调用点，且是「事后旁白」而非「决策」

- 调用点唯一：`loop.js:635`（`ai.thought.generate`）。grep `gateway.complete` 在 `loop.js` 中无第二处。
- 行动先定后叙述：`decide()`（`loop.js:273`）在 :326 用 `scoreFn` 选行动 → :634 才把该行动写进提示词。
- 结论：LLM 是**叙事层**，行动由规则评分器决定。

### ② 没有任何智能体间对话机制

- `src/` 全库 grep `speech|dialogue|conversation|utterance`：**零命中**（除 `router.js` 的 task 名占位）。
- `ai.speech` 在结构树中 state=`planned`（未实现）；`ai.prompt.world` 同为 planned。
- 观察到的全部文字都是**独白**，无一句面向其他居民。

### ③ LLM 输出对仿真**零因果影响**（最关键的发现）

因果链与其断点：

| 环节 | 位置 | 去向 | 是否影响行动 |
| --- | --- | --- | --- |
| `thought.thought` | loop.js:661 | 写入情景记忆（tags=['thought',action]） | — |
| 情景记忆 recall(limit 3) | loop.js:277 | → `context.assemble` → `ranked` | **否** |
| `ranked` | loop.js:288 | 仅 loop.js:373 `topDriver`（观察者日志） | **否** |
| 语义记忆 recall | loop.js:321 | 仅 loop.js:377 观察者日志 `context.semantic` | **否** |
| 行动评分 `scoreFn` | loop.js:326-337 | `scoreAction + personality.evaluate + 模拟期望效用` | 是（**无记忆项**） |

即：`ranked` 与 `semanticMemories` 的唯一消费者是观察者日志（:373/:377）；评分函数里没有任何记忆项。
**因此 LLM 写出的思考既不影响自己下一步，也不影响他人。**

### ④ 提示词里 persona 是常量占位，name 是编号

- `loop.js:771` 播种：`name = 居民${i+1}`；`spawnAgent` 默认 `persona='一名普通避难所居民'`（:231）。
- 故 50 个居民的 `persona` **完全相同**；差异只来自 50 标签与性格画像。
- 副作用：样本中 `agent_...001` 自述「林一……叫我吧。反正我叫不上别的名字」——把世界观里的避难所名 `LinYi` 误当己名。

### ⑤ 文字层面的具体缺陷（逐条可在上方原文中定位）

| 现象 | 位置 | 证据 |
| --- | --- | --- |
| 处境回音 | 4/7 条以「一切如常」原样开头 | 提示词 situation 就是 `一切如常`，模型直接照抄 |
| 英文枚举泄漏 | `agent_...002` tick2 | 原文写「我决定外出**forage**。」——行动键名混入中文散文 |
| 幻觉第二人称 | `agent_...002` tick1 | 「我低着头，默不作声地跟在你身后」——世界模型里没有「你」 |
| 单条内退化重复 | `agent_...002` tick2 | 「我从一堆堆堆积如山的空罐头箱里翻找，动作僵硬却带着一丝近乎本能的执着」**同段出现两次** |
| 跨 tick 近逐字复制 | `agent_...003` tick1 vs tick2 | 开头「我小心翼翼地戴上破损的头盔和旧手套」、结构与结尾几乎一致 |
| 不知己名 | `agent_...001` tick1 | 自述「叫我吧。反正我叫不上别的名字」 |

### ⑥ 必须避免的误读

3 个居民都选 `forage`，且所有文字都在叙述采集——**这不构成决策质量证据**：
行动是注入提示词的既成事实，叙述与行动一致是**构造上必然**，不是模型判断的结果。
