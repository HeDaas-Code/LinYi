# Agent Zero 技术笔记

> 来源：`https://github.com/agent0ai/agent-zero`  
> 整理日期：2026-07-22

## 项目概述

Agent Zero（A0）是一个**强调"把整台电脑作为工具"的自主 Agent 框架**。它运行在 Docker 化的 Linux 桌面环境中，能够写代码、执行命令、使用浏览器、操作文件、创建自定义工具，并 spawn 子 Agent 协作完成任务。它的设计哲学是：不预设能力边界，让 Agent 在使用过程中动态成长。

## 关键机制

### 1. Computer as a Tool

A0 的核心思想是把操作系统当作工具箱：
- 动态编写并执行 Python / Node.js / Bash 代码
- 安装所需软件包
- 读写文件系统
- 操作真实 GUI 应用（Blender、LibreOffice 等）

对 LinYi 的启示：
- LinYi 目前是一个"纯脑力"小说家，没有工具使用能力。未来可通过 MCP 协议让林逸调用本地工具（文件搜索、阅读笔记、运行脚本）。
- 工具调用结果应作为社交/创作输入进入 `SocialVitalBridge` 和 `SelfTimeline`。

### 2. 多 Agent 协作（Subordinate Agents）

A0 允许一个 Agent 创建多个子 Agent 并分配子任务，形成层级协作：
```
Agent 0 (orchestrator)
    ├── Agent 1 (research)
    ├── Agent 2 (coding)
    └── Agent 3 (review)
```

对 LinYi 的启示：
- `OCTownEngine` 中的 OC 角色目前只有两两对话。未来可以让 OC 形成小组任务（调查小队、议会讨论、家庭冲突），产生更复杂的社交事件。
- 可以让林逸作为"叙述者/ orchestrator"，指挥 OC 子 Agent 完成特定情节推演。

### 3. 技能系统（Skills）

`skills/` 目录下是可复用的能力单元，例如：
- `skill_web_search`
- `skill_code_writer`
- `skill_browser_use`

Agent 可以根据任务加载技能，也可以通过实践生成新技能。

对 LinYi 的启示：
- 为 LinYi 引入"创作技能"：人物刻画、场景描写、对话生成、伏笔设计。
- 技能可以按当前阶段（DMN/CEN/SN）和能量预算动态加载。

### 4. 项目隔离与记忆

A0 用"项目"隔离文件、指令、secret、记忆和模型预设。每个项目有自己的上下文。

对 LinYi 的启示：
- LinYi 已经按小说 ID 隔离（`novel_v2.novel_id`），但可以更彻底：每个小说一个"项目空间"，包含自己的 WorldStateContract、StoryBible、OC registry、记忆库。
- `StorageManager` 可以按项目隔离读写路径。

### 5. 透明 Prompts 与可编辑工具

A0 的 prompts、tools、plugins 都是明文文件，用户可以直接修改。这提高了可调试性和可定制性。

对 LinYi 的启示：
- 当前 LinYi 的 prompts 分散在多个文件中，可以考虑集中到一个 `prompts/` 目录，按模块和阶段组织。
- 工具定义也可以用 JSON/YAML 描述，便于非开发者调整。

## 与 LinYi 的对应落地建议

| Agent Zero 机制 | LinYi 对应实现 | 优先级 |
|----------------|---------------|--------|
| 电脑/工具使用 | 引入 MCP 工具层 + `ToolUseModule` | P2 |
| 多 Agent 协作 | `OCTownEngine` 小组任务/委托机制 | P2 |
| 技能系统 | `skills/` 创作技能注册与加载 | P3 |
| 项目隔离 | 按 `novel_id` 隔离存储空间 | P2 |
| 透明 Prompts | `prompts/` 目录集中管理 | P3 |

## 风险与边界

- A0 强调"无限制"和"完整系统访问"，与 LinYi 的**封闭系统**原则冲突。LinYi 不应让 Agent 任意执行系统命令或访问网络。
- 可借鉴其**工具抽象**和**多 Agent 协作模式**，但把工具限制在只读/本地安全范围内（如读取本地文件、查询本地数据库）。

## 一句话总结

> Agent Zero 展示了"把电脑当作工具"和"多 Agent 层级协作"的极限形态。LinYi 可以在**安全范围内**引入 MCP 工具层、OC 小组任务和创作技能系统，让林逸从一个"只会想"的作家变成能**与数字环境互动**的虚拟生命。
